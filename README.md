# Dashboard Visualisasi Data Penjualan — CASE1

## Deskripsi Proyek
Proyek ini merupakan implementasi analisis dan visualisasi data penjualan menggunakan Python. Data diolah dan disajikan melalui dashboard interaktif berbasis Streamlit untuk membantu pengguna memahami informasi transaksi penjualan serta melihat performa penjualan melalui berbagai bentuk visualisasi.

## Tujuan
- Melakukan pengolahan dan analisis terhadap dataset penjualan.
- Menyajikan informasi penjualan dalam bentuk visualisasi yang mudah dipahami.
- Mengidentifikasi informasi dan pola yang terdapat dalam data penjualan.
- Mengembangkan dashboard interaktif sebagai media penyajian hasil analisis data.

## Fitur Dashboard
- Menampilkan ringkasan informasi dari dataset penjualan.
- Menyajikan visualisasi data penjualan menggunakan grafik interaktif.
- Menampilkan informasi terkait transaksi dan performa barang.
- Menyediakan tampilan dashboard yang interaktif dan mudah digunakan.

## Teknologi yang Digunakan
- Python
- Jupyter Notebook
- Pandas
- Streamlit
- Plotly
- Git dan GitHub

## Cara Menjalankan Proyek

1. Clone repository GitHub:

   ```bash
   git clone https://github.com/yenseason/CASE1.git
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd CASE1
   ```

3. Install seluruh library yang dibutuhkan:

   ```bash
   pip install -r requirements.txt
   ```

4. Jalankan aplikasi Streamlit:

   ```bash
   streamlit run app.py
   ```

5. Buka alamat lokal yang ditampilkan pada terminal untuk melihat dashboard.
